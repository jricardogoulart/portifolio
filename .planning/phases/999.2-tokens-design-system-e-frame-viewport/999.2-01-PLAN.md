# Plan 999.2-01: Sistema de Design Tokens, Paleta Editorial e Moldura Viewport

## Objective
Estabelecer o design system fundamental extraído de `design.md` com total fidelidade ao site de referência (https://www.runrobrun.com/):
1. Injetar todos os tokens de cores, superfícies, espaçamento e shape no `src/index.css`.
2. Aplicar a regra estrita de zero border-radius (`--radius-all: 0px`).
3. Adicionar o frame fixo de 8px solid (`#AAAACC`) contornando `100vw × 100vh` via `src/App.tsx` e `src/index.css`.
4. Ajustar `index.html` para fixar o background editorial `#D8D8D8`.

<threat_model>
- Sem ingestão de inputs externos não confiáveis nesta fase puramente visual/estilística.
- Garantir `pointer-events: none` no frame fixo para não bloquear cliques, scrolls ou foco de acessibilidade.
</threat_model>

- Cores de fundo: `--color-bg-primary: #D8D8D8`, `--color-bg-secondary: #C8C8CC`, `--color-bg-overlay: rgba(220, 220, 225, 0.9)`
- Cores de texto: `--color-text-primary: #111111`, `--color-text-secondary: #333333`, `--color-text-inverted: #ffffff`
- Acentos: `--color-accent-orange: #FF5C1A`, `--color-accent-orange-sq: #FF4500`
- Bordas e moldura: `--color-border-frame: #AAAACC`, `--color-border-crosshair: #888888`, `--border-frame-width: 8px`
- Cores 3D: `--color-3d-primary: #FF7A5A`, `--color-3d-secondary: #FFB0A0`, `--color-3d-shadow: #CC4422`
- Formas: `--radius-all: 0px`
- Espaçamento: `--space-xs: 4px`, `--space-sm: 8px`, `--space-md: 16px`, `--space-lg: 32px`, `--space-xl: 64px`, `--space-2xl: 120px`

Adicionar a regra universal de reset brutalista:
```css

  border-radius: var(--radius-all, 0px) !important;
}
```

Configurar as propriedades base do body:
```css
body {
  background-color: var(--color-bg-primary, #D8D8D8);
  color: var(--color-text-primary, #111111);
  margin: 0;
  padding: 0;
  overflow-x: hidden;
  font-feature-settings: "cv02", "cv03", "cv04", "cv11";
}
```

- .planning/phases/999.2-tokens-design-system-e-frame-viewport/999.2-CONTEXT.md

<action>
1. Em `src/index.css`, criar a classe `.viewport-frame`:
```css

  position: fixed;
  inset: 0;

}
```

</action>
