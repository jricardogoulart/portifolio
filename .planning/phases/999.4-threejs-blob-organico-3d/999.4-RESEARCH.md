## 1. Domain & Architecture Analysis

### Shader GLSL de Ruído Simplex 3D
Para morphing orgânico sem dependências pesadas externas, a melhor abordagem comprovada na indústria é o algoritmo de Ashima Arts / Stefan Gustavson para **Classic 3D Simplex Noise** implementado diretamente no Vertex Shader GLSL.

**Vantagens:**
- Execução 100% na GPU (Zero custo de CPU para deformar milhares de vértices por frame).
- `IcosahedronGeometry(radius, 64)` oferece densidade poligonal ideal para deformações aveludadas sem serrilhado.
- Controle direto de `uTime`, `uFrequency` e `uAmplitude` via Uniforms do Three.js.

### Simulação de Subsurface Scattering (SSS) e Fresnel no Fragment Shader
Para atingir o visual aveludado e orgânico de `runrobrun.com`:
- **Cores Uniforms:**
  - `uColorPrimary`: `#FF7A5A` (coral base)
  - `uColorSecondary`: `#FFB0A0` (highlight/fresnel)
  - `uColorShadow`: `#CC4422` (sombra profunda)
- **Cálculo de Fresnel:**
  ```glsl
  vec3 viewDir = normalize(-vViewPosition);
  float fresnel = pow(1.0 - max(dot(vNormal, viewDir), 0.0), 2.5);
  ```
- **Wrap Diffuse Lighting (Simulação de translucidez):**
  A iluminação difusa envolve os contornos simulando a passagem de luz através da matéria biológica.

## 2. Padrões de Integração no React 19

- **Container Ancorado:**
  O canvas é anexado à `div#hero-3d-portal` em `src/components/HeroBrutalist.tsx` com `alpha: true` no `WebGLRenderer`.
- **ResizeObserver com DevicePixelRatio limitado:**
  ```ts
  const dpr = Math.min(window.devicePixelRatio || 1, 2);
  renderer.setPixelRatio(dpr);
  renderer.setSize(width, height);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
  ```
- **Rastreamento de Cursor com Inércia (Lerp):**
  ```ts
  mouse.current.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.current.y = -(event.clientY / window.innerHeight) * 2 + 1;
  // No render loop:
  currentRotation.x += (mouse.current.y * 0.4 - currentRotation.x) * 0.05;
  currentRotation.y += (mouse.current.x * 0.4 - currentRotation.y) * 0.05;
  ```
- **Descarte Rigoroso de Recursos de GPU (Memory Leak Prevention):**
  No retorno do `useEffect`:
  - `cancelAnimationFrame(rafId)`
  - `resizeObserver.disconnect()`
  - `window.removeEventListener('pointermove', onPointerMove)`
  - `geometry.dispose()`
  - `material.dispose()`
  - `renderer.dispose()`
  - Remoção de `renderer.domElement` da árvore DOM.
