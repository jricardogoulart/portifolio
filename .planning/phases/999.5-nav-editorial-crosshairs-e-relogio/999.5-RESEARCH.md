# Phase 999.5: Navegação Editorial, Marcas de Registro Crosshairs e Relógio ao Vivo - Research

**Date:** 2026-10-16
**Status:** Completed

## 1. Arquitetura da Barra de Navegação Editorial

A navegação de `runrobrun.com` adota a estética editorial suíça:
- **Posição e Camada:** `position: fixed; top: 1.5rem; left: 2rem; right: 2rem; z-index: 100;`
- **Interação:** O container da barra usa `pointer-events: none`, enquanto os links e o branding usam `pointer-events: auto`, garantindo que a área vazia entre a esquerda e a direita não bloqueie interações com o canvas 3D ou com o texto de fundo.
- **Microinterações:**
  - Hover nos links: sublinhado invisível por padrão com transição rápida de cor ou leve opacidade.
  - Quadrado laranja `■` (`#FF4500`): rotação suave de 45° ou escala no hover de `LET'S CREATE`.
  - Scroll suave:
    ```ts
    const scrollToSection = (id: string) => {
      const element = document.getElementById(id);
      if (element) {
        element.scrollIntoView({ behavior: 'smooth' });
      }
    };
    ```

## 2. Crosshairs de Registro Gráfico (Offset Printing Marks)

Em design editorial suíço, marcas de cruz `+` remetem a guias de registro de impressão tipográfica:
- **Posicionamento:** 4 cantos do container do Hero inicial com alinhamento absoluto:
  - Top-left: `top: 1.25rem; left: 1.5rem;`
  - Top-right: `top: 1.25rem; right: 1.5rem;`
  - Bottom-left: `bottom: 1.25rem; left: 1.5rem;`
  - Bottom-right: `bottom: 1.25rem; right: 1.5rem;`
- **Propriedades:** `color: var(--color-border-crosshair, #888888); font-family: var(--font-mono); font-size: 0.9rem; pointer-events: none; user-select: none;`.

## 3. Integração com as Seções Existentes

- **Target dos Links:**
  - `ABOUT`: seletor `#about` ou topo da seção de bio em `About.tsx`.
  - `WORK`: seletor `#portfolio` (Seção 04 contendo os projetos reais do GitHub integrados na Phase 999.1).
  - `LET'S CREATE ■`: seletor `#contact` ou modal/link direto.

## 4. Validation Architecture

- **Validação de Scroll:** O clique em cada link navega suavemente até o elemento de destino sem saltos abruptos.
- **Validação Visual:** O quadrado laranja `#FF4500` se destaca com nitidez e os crosshairs decoram os 4 cantos sem sobrepor os textos do Hero.
- **Validação de Build:** `npm.cmd run build` executa sem nenhum erro.
